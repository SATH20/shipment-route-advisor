How it decides

Five simple steps, every time

  1. 1. Check the rules

    Batteries can't fly. Some customers say no Red Sea. Some ways are simply too slow.

  2. 2. Imagine 5,000 trips

    Like rolling dice: some trips run late, a few hit real trouble. Now we know the odds.

  3. 3. Drop the losers

    If one way is worse than another in every way, nobody should pick it.

  4. 4. Add up the real cost

    Ticket, late fees, losses from trouble and pollution, all in dollars. Lowest wins.

  5. 5. Double-check

    Change our guesses a little and decide again, 100 times. Then say how sure we are.
